# Your Approved Project Title

**Tutor Match AI: A Tutor-Student Matching and Recommender System using K-Nearest Neighbors (KNN)**

## Summary

Tutor Match AI is a proposed system designed to help students find suitable tutors based on their preferred subjects, hourly rates, ratings, learning styles, and availability. The initial Flutter Web prototype includes a Home page that displays sample tutor profiles with their subjects, hourly rates, and ratings, as well as a Login page with basic input validation. The system aims to make tutor searching more convenient and organized. The REST API, PostgreSQL database, and K-Nearest Neighbors (KNN) recommendation feature are planned for future development.

## Current Stack

- **Frontend:** Flutter Web
- **Programming Language:** Dart
- **Version Control:** Git and GitHub
- **Planned Backend:** REST API
- **Planned Database:** PostgreSQL
- **Planned Recommendation Algorithm:** K-Nearest Neighbors (KNN)

## Run Locally

To install the project dependencies, open the project folder in VS Code and run:

```bash
flutter pub get
```

To launch the Flutter Web application in Google Chrome, run:

```bash
flutter run -d chrome
```
